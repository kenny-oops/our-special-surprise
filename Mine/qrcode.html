How to Publish Online for Free in 3 Minutes:

  • 1 Free Option 1: Netlify Drop (Easiest & Fastest)
    Go to app.netlify.com/drop, drag and drop this entire project folder into the browser window. Within 10 seconds, Netlify gives you a free HTTPS link!
  • 2 Free Option 2: GitHub Pages
    Upload the files to a new repository on GitHub named our-little-forever. Go to Settings → Pages and select the main branch. Your link will be https://yourusername.github.io/our-little-forever/.
  • 3 Free Option 3: Vercel
    Import your repository or drag-and-drop the directory via Vercel CLI / Dashboard for an instant HTTPS URL.
  • 4 Generate & Print!
    Paste your final HTTPS link above, generate the QR code, and print the gift card below.
